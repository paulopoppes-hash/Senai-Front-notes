Front Notes - Anotacoes das Aulas

Repositorio de conteudos e anotacoes da disciplina Frameworks Front-end.

Aula 01 - Vanilla JavaScript

Fundamentos do JavaScript nativo, manipulacao de DOM e evento de clique.

  • Manipulacao da arvore DOM
  • Event listeners (click)
  • Gestao de estado e logica condicional

Aula 03 - Frameworks Front-end

React, Vue.js, Angular e Next.js: componentes, props e renderizacao.

  • Componentes funcionais
  • JSX e template
  • Props e fluxo de dados

Aula 04 - Consumindo APIs

APIs REST, protocolo HTTP, Express.js e consumo de dados via fetch.

  • Metodos HTTP (GET, POST, PUT, DELETE)
  • JSON e endpoints
  • CORS e consumo de API

Aula 05 - Criando APIs

API RESTful com CRUD, persistência em JSON e consumicao por front-end.

  • Rotas CRUD (listar, buscar, criar, editar, excluir)
  • Persistencia em arquivo JSON
  • Documentacao com Postman
