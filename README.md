# Senai-Front-notes

Anotações e conteúdos das aulas — Frameworks Front-end

## Descrição

Repositório de anotações e conteúdos das aulas da disciplina Frameworks Front-end, servindo como índice e material de consulta dos estudos desenvolvidos ao longo do semestre.

## Conteúdo por aula

- **Aula 01:** Vanilla JavaScript — manipulação de DOM, event listeners, gestão de estado
- **Aula 03:** Frameworks Front-end — React, Vue.js, Angular, Next.js
- **Aula 04:** Consumindo APIs — REST, HTTP, Express.js, fetch
- **Aula 05:** Criando APIs — CRUD, persistência JSON, Postman

## Tecnologias

- HTML5
- CSS3
- JavaScript
